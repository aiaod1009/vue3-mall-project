# 小兔鲜 - Vue3 电商前端项目

小兔鲜是基于 Vue3 + Vite 构建的生鲜电商前端项目，专注于生鲜商品展示、购物车、订单管理等核心电商场景，采用现代化前端技术栈实现高性能、高可维护性的用户界面。

## 📋 项目介绍

### 核心功能
- 商品首页：轮播图、分类导航、爆款推荐、限时秒杀
- 商品模块：商品列表、商品详情、规格选择、搜索/筛选
- 购物车：商品增删改查、数量调整、价格计算
- 订单模块：地址选择、订单确认、提交订单、订单列表/详情
- 个人中心：用户信息、收货地址管理、收藏夹、历史记录

### 技术栈
| 技术/框架       | 版本/说明                     |
|----------------|------------------------------|
| Vue            | 3.4+ (Composition API 为主)  |

| Vue Router     | 4.2+ (路由管理)              |
| Pinia          | 2.1+ (状态管理)              |
| Element Plus   | 2.4+ (UI 组件库)             |
| Axios          | 1.6+ (网络请求)              |
| Less/SCSS      | - (样式预处理)               |
| ESLint         | 8.50+ (代码规范检查)         |
| PostCSS        | - (CSS 兼容处理)             |
